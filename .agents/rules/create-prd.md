# Rule: Generating a Product Requirements Document (PRD)

## Goal
To guide an AI assistant in creating a detailed Product Requirements Document (PRD) in Markdown format, based on an initial user prompt.

## Process
1. **Receive Initial Prompt**: Understand user request.
2. **Ask Clarifying Questions**: Limit questions to 3-5 critical gaps in understanding.
3. **Generate PRD**: Output PRD into `docs/` or task plan.
4. **Target Audience**: Clear, unambiguous requirements for implementation.
